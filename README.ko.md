# 🎲 루미큐브 웹 애플리케이션 (Rummikub Web App)

<div align="center">

[English](README.md) | 한국어

**루미큐브(Rummikub)** 보드게임을 브라우저에서 즐길 수 있는 HTML5 & TypeScript 기반의 반응형 웹 애플리케이션입니다.  
지능형 4단계 AI 봇과의 싱글 플레이 및 WebRTC 기반의 실시간 서버리스 P2P 온라인 멀티플레이를 지원합니다.

## 🌟 주요 특징

- **🎮 2가지 게임 모드 지원**:
  - **싱글플레이**: 최대 3명의 AI 봇과 함께 플레이 (봇별 개별 난이도 설정 가능).
  - **온라인 멀티플레이**: PeerJS(WebRTC)를 활용한 실시간 서버리스 P2P 방식으로 2~4명 플레이. 별도의 회원가입이나 중앙 서버 없이 방 코드 복사 및 공유만으로 즉시 대전 가능!
- **🤖 4단계 AI 봇 & 원클릭 승급 시스템**:
  - **초급**, **중급**, **고급**, **최고급**의 4단계 지능형 전략 탑재.
  - 게임 도중 언제든지 봇 카드를 클릭하면 난이도가 즉시 한 단계씩 순환 승급 (`초급 ➔ 중급 ➔ 고급 ➔ 최고급 ➔ 초급`).
  - **30초 생각 시간 제한 가드**: 비동기 분할 연산(`yieldTick`)으로 화면 멈춤을 방지하고, 실시간 초 단위 카운트다운 타이머 제공.
- **🎨 직관적인 보드 레이아웃 & 타일 배치**:
  - **왼쪽 아래 ➔ 위로 쌓이는 세트 배치**: 공용 테이블의 세트들이 왼쪽 하단(바닥)에서 시작하여 가로로 채워지고, 줄이 바뀔 때마다 위쪽으로 차곡차곡 쌓여 올라갑니다.
  - **보드 타일 자동 축소 (Auto-Scaling)**: 등록된 세트가 많아지면 타일 크기가 4단계(`기본` ➔ `compact` ➔ `dense` ➔ `ultra-dense`)로 자동 축소되어 넓은 시야를 확보합니다.
  - **"새 세트 만들기" 드롭존 최적화**: 공용 테이블 하단 중앙에 슬림한 세로 길이(52px)로 배치되어 손쉬운 타일 등록 지원.
- **🌙 고대비 컬러풀 다크 모드**:
  - 라이트 모드와 화려한 다크 모드 원클릭 토글.
  - 다크 모드에서는 타일 바탕색이 선명한 4색(빨강, 밝은 노랑, 초록, 산뜻한 파랑)으로 채워지며, 가독성을 극대화한 폰트 색상과 전용 조커 디자인이 적용됩니다.
- **📱 완벽한 반응형 & 모바일 풀스크린 지원**:
  - 데스크톱 PC 대화면 전용 1.5배 확대 타일(64×90px) 및 최적화된 컨트롤 크기.
  - 스마트폰(iPhone 등)의 가로/세로 화면에 맞춘 레이아웃 최적화 및 원클릭 네이티브 **전체화면(Fullscreen)** 모드 지원.
- **🏆 지속형 논모달(Non-modal) 중앙 대형 승리 배너**:
  - 게임 승리 시 화면을 가리는 팝업창 대신, 화면 중앙에 커다랗고 화려한 지속형 승리 축하 배너(`🏆 축하합니다! [플레이어] 승리하셨습니다!`)가 표시됩니다.
- **🔄 방 퇴장 시 봇 자동 승계**:
  - 멀티플레이 중 플레이어가 퇴장하더라도 해당 플레이어의 패를 AI 봇이 즉시 이어받아 게임이 중단 없이 진행됩니다.

## 📜 루미큐브 게임 규칙

총 106개의 타일로 진행됩니다:
- **1부터 13까지의 숫자 타일** 4개 색상(**빨강**, **노랑**, **파랑**, **검정**) 각 2세트 (104개)
- 어떤 숫자와 색상으로도 대체 가능한 **조커 타일 2개**

### 1. 유효한 세트 (Meld) 조건
테이블 위의 모든 세트는 반드시 **최소 3개 이상의 타일**로 구성되어야 합니다:
- **그룹 (Group)**: 숫자는 같고 **색상이 모두 다른** 3개 또는 4개의 타일 (예: `빨강 7`, `파랑 7`, `노랑 7`)
- **런 (Run)**: 색상이 같고 **숫자가 연속되는** 3개 이상의 타일 (예: `검정 4`, `검정 5`, `검정 6`, `검정 7`)

### 2. 최초 등록 (Initial Meld)
- 처음으로 테이블에 타일을 내려놓을 때는 **오직 자신의 핸드(거치대)에 있는 타일만으로** 세트를 구성해야 합니다.
- 내려놓는 세트들의 **숫자 총합이 30점 이상**이어야 등록할 수 있습니다.
- 최초 등록을 완료한 이후 턴부터는 테이블 위에 있는 다른 타일들을 자유롭게 재조합할 수 있습니다.

### 3. 테이블 재조합 (Manipulation)
- 기존 세트에 타일 덧붙이기
- 긴 런 세트를 둘 이상의 유효한 세트로 쪼개기
- 테이블의 조커를 해당 위치의 일반 타일로 교체하고, 가져온 조커를 같은 턴에 즉시 다른 세트에 사용하기

### 4. 턴 종료 및 벌칙
- **턴 완료** 버튼을 눌렀을 때 테이블 위에 3개 미만이거나 규칙에 맞지 않는 세트가 있으면 원래 상태로 롤백되며 벌칙 타일 1장을 받습니다.
- 낼 타일이 없거나 패를 아끼고 싶다면 타일 1장을 드로우하고 턴을 넘길 수 있습니다.

|:---:|:---|:---:|:---|

| 🔴 | **최고급** | 최대 20초 | 복합 다중 분할, 테이블에 배치된 조커 회수 및 재사용, 핸드 타일 최적 배출 전략을 구사합니다. |

## 🛠️ 기술 스택

- **언어**: [TypeScript](https://www.typescriptlang.org/) (Strict mode)
- **번들러**: [Vite](https://vitejs.dev/)
- **네트워킹**: [PeerJS](https://peerjs.com/) (WebRTC P2P DataChannels 기반)
- **스타일링**: 순수 CSS3 (CSS Custom Properties, Flexbox, 반응형 미디어 쿼리)
- **배포**: [GitHub Pages](https://pages.github.com/) (GitHub Actions 자동 빌드 및 배포)

## 🚀 시작하기

### 사전 준비사항
- [Node.js](https://nodejs.org/) (v18 이상 권장)
- `npm` (Node.js 설치 시 기본 포함)

### 설치 및 로컬 실행

1. 저장소 클론:
   ```bash
   git clone https://github.com/MaroShim/Rummikub.git
   cd Rummikub
   ```

2. 의존성 패키지 설치:
   ```bash
   npm install
   ```

3. 로컬 개발 서버 실행:
   ```bash
   npm run dev
   ```
   브라우저에서 `http://localhost:5173`으로 접속합니다.

### 프로덕션 빌드

배포용 정적 파일을 빌드합니다:
```bash
npm run build
```
빌드된 파일은 `dist/` 폴더에 생성됩니다.

로컬에서 프로덕션 빌드를 미리보기:
```bash
npm run preview
```
